# MacPaint User's Guide: terminology

Stage 1, 21 October 2026. The words the book uses. These rules apply in
order:

1. Text MacPaint itself shows (menus, dialogs, alerts) is quoted
   exactly.
2. Otherwise, use the original Apple manual's word (MP), unless a
   clearer one is noted.
3. British spelling throughout, except quoted program text.

## Screen

| Book term | Notes |
|---|---|
| menu bar | Apple, File, Edit, Goodies, Font, FontSize, Style |
| drawing window | MP. "the window" once it's been introduced. 416 × 240 pixels, no scroll bars |
| page | The whole picture: 8 × 10 inches (576 × 720 dots). The window shows about a third of it (MP) |
| tool palette | MP. The 20 tools on the left |
| line and border widths | MP's "border palette" is used once, then "the line widths". The dotted top choice is "no border" (from the Introduction screen) |
| patterns | The 38 patterns along the bottom. "pattern palette" in Reference only |
| current pattern | MP. The large sample at the left of the patterns |
| dot | One screen dot (a pixel). The period word; "pixel" is avoided |
| insertion point | MP. The blinking bar when typing |
| marching ants | Avoided. Say "the dotted outline moves", as MP describes a selection |

## Actions and states

| Term | Use |
|---|---|
| select, selection | "The selection" is what is inside the dotted outline |
| put down (a selection) | What happens when you click elsewhere: the selection becomes part of the picture again. Used for the I2 behaviour. Not "deselect" |
| Clipboard | Capital C, as Apple's manuals of the time wrote it. Holds one item; replaced by each Cut or Copy |
| Scrapbook | Capital S. The desk accessory that keeps many items |
| scrap | Only inside quoted alerts ("…trouble writing the scrap."). Glossary: "the Mac's word for what's on the Clipboard" |
| FatBits | One word, as in the menu |
| Show Page | The command and its view |
| work files | The temporary files "Paint1" and "Paint2". Named only in Appendix B |
| startup disk | The disk with the System Folder you started from |
| choose | Menu commands ("Choose Copy from the Edit menu") |
| click, double-click, drag, press | Apple's terms. Keys: "press Shift", "hold down Option" |
| ⌘ | "Command key (⌘)" at first use, "⌘" after. "⌘-Q" style for shortcuts |
| Backspace, Enter, Return, Option, Shift, Caps Lock, \` | Mac Plus key names. Undo is "the \` key (at the top left)" |

## Words to avoid

These are modern or wrong for the period: pixel, click-and-drag,
right-click, scroll bar (MacPaint has none), zoom, layer, canvas, app,
icon bar, toolbar, select all (say "double-click the selection
rectangle"), desktop picture, save file (say "save your picture" or
"save the document").
